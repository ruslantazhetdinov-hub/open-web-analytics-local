# Локальный стенд Open Web Analytics

Стенд поднимает Open Web Analytics 1.14.0, MariaDB, фоновый планировщик и небольшой тестовый сайт.

## Запуск

1. Запустите Docker Desktop и дождитесь статуса «Engine running».
2. Скопируйте `.env.example` в `.env` и замените пароли, адреса и домены.
3. Откройте PowerShell в этой папке.
4. Выполните `./start.ps1`.
5. Откройте тестовый сайт: http://localhost:8081/
6. Нажмите несколько кнопок и обновите страницу.
7. Откройте OWA: http://localhost:8080/

Логин — `admin`. Первый пароль совпадает со значением `OWA_DB_PASSWORD` в `.env`.

Файл `.env` намеренно не попадает в Git: в нём находятся пароли и адреса конкретной установки. В репозитории хранится только безопасный `.env.example`.

## Полезные команды

- Остановить стенд без удаления данных: `./stop.ps1`
- Посмотреть состояние: `docker compose ps`
- Посмотреть журнал OWA: `docker compose logs -f owa`
- Полностью пересоздать учебные данные: `./reset.ps1`

## Перед установкой клиенту

- Поставьте HTTPS и обратный прокси перед OWA.
- Замените все секреты в `.env` и не храните этот файл в Git.
- Укажите реальный `OWA_PUBLIC_URL`, домен сайта и часовой пояс до начала сбора.
- Согласуйте срок хранения данных; сейчас задано 24 месяца.
- Настройте резервное копирование MariaDB и проверьте восстановление.
- Добавляйте трекер только после согласия пользователя, если это требуется применимыми правилами и политикой сайта.
- Для доступности из интернета не публикуйте порт базы данных.
